
# SISTEMA MUSICAL 🎵

**Projeto de Desenvolvimento Web**

Repositório destinado ao desenvolvimento de um Sistema Musical, criado com HTML5 e CSS3.

O projeto apresenta uma plataforma para organização de músicas e artistas, contendo tela de login, menu principal, cadastro de artistas, cadastro de músicas e biblioteca musical.

**Tecnologias utilizadas:** HTML5 e CSS3.
